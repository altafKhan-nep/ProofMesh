## Brand & Style

This design system establishes an exacting, scientific-grade visual language for developer attestation and Solana skill verification. Departing consciously from speculative, dark-mode crypto conventions, the identity is anchored in deliberate clarity, institutional trustworthiness, and empirical proof. It treats code quality and verification proofs with the seriousness of an academic monograph or clinical measurement instrument.

The design movement is **Minimalist Precision** blended with **Scientific Data Architecture**. Key traits include:
- High-density information delivery rendered through generous macro whitespace paired with precise micro spacing.
- Deliberate warm-paper neutral canvases that soften high-contrast data, reducing cognitive fatigue during extended audit reviews.
- A restrained, authoritative deep evergreen chromatic accent used strictly for verified outcomes, cryptographic integrity badges, and primary interactive commitments.
- Clean technical monospaced telemetry tokens juxtaposed against tightly tracked modern sans-serif typography.

## Colors

The color palette reinforces verification, paper-based trust, and scientific documentation.

- **Primary (`#1D5D3A`)**: A deep, balanced botanical pine green. Reserved strictly for primary state actions, affirmative verification tags, confirmed on-chain transactions, and verified credential banners.
- **Secondary (`#2B4736`)**: A grounded, deep olive-slate used for secondary framing, metadata headers, and structural UI divisions.
- **Tertiary (`#86EFAC` / `#B8FF66`)**: A vibrant luminescent accent inspired by laser telemetry and Alethia data highlights, used sparingly for real-time node indicators, active status dots, and live telemetry pulses.
- **Neutral Surface Canvas (`#F9F8F6` & `#F4F3EF`)**: Warm-paper tones replace harsh stark white or dark crypto backgrounds. High-contrast near-black typography (`#111413`) ensures rigorous legibility and WCAG AAA compliance.
- **Borders (`#E5E4DE`)**: Subtle stone lines providing disciplined structural boundaries without visual noise.

## Typography

The typographic hierarchy prioritizes systematic density, strict vertical metrics, and optical tension:
- **Headlines (Geist)**: Rendered with deliberate negative letter tracking (`-0.02em` to `-0.04em`) to mirror high-end editorial and scientific layouts. Headings are sharp, direct, and compact.
- **Body Text (Geist)**: Tuned for reading dense audit reports, commit logs, and skill summaries. Balanced optical shapes prevent reader fatigue against the `#F9F8F6` canvas.
- **Labels & Metrics (JetBrains Mono)**: Monospaced typography is mandatory for on-chain signatures, Solana transaction hashes, commit hashes, credential IDs, and protocol telemetry. JetBrains Mono provides unambiguous glyph differentiation (e.g., zero vs. 'O', digit 1 vs. lowercase 'l') critical for cryptographic transparency.

## Layout & Spacing

This design system uses a strict **12-column responsive fluid grid** with an underlying 4px baseline rhythm.

- **Desktop (>= 1200px)**: 12-column grid, max-width `1280px` or `1440px`, 48px canvas margin (`margin`), and 24px column gutter (`gutter`).
- **Tablet (768px - 1199px)**: 8-column grid with 32px canvas margin and 16px column gutter.
- **Mobile (< 768px)**: 4-column grid with 20px canvas margin (`margin-mobile`) and 12px column gutter (`gutter-sm`).

### Layout Philosophy
1. **Asymmetric Data Splitting**: Editorial content is anchored to wide spans (columns 1–7) with verification metrics, signature attestations, and badge chips arrayed in compact columns (8–12).
2. **Dense Metric Cards**: Components cluster related data using `space-xs` and `space-sm` internal padding, while section boundaries breathe with `space-xl` and `space-2xl`.

## Elevation & Depth

To avoid synthetic drop-shadows typical of consumer software, this design system relies on **Tonal Stratification** paired with **Micro-Luminescent Ambient Occlusion**:

1. **Surface Layers (Tonal Stacking)**:
   - Level 0 (Canvas): Base background `#F9F8F6`.
   - Level 1 (Panels & Sub-sections): Warm structural surface `#F4F3EF`.
   - Level 2 (Interactive Cards & Code Inspects): Crisp opaque white `#FFFFFF` outlined with `1px solid #E5E4DE`.
2. **Ambient Shadow Character**:
   - Cards and dropdowns utilize a low-contrast, multi-stop diffuse shadow tinted with cool slate rather than pure black:
     `0 1px 2px rgba(17, 20, 19, 0.04), 0 4px 16px -2px rgba(17, 20, 19, 0.06)`.
   - Floating overlays (tooltips, verification dialogs):
     `0 8px 30px -4px rgba(17, 20, 19, 0.08), 0 0 1px rgba(17, 20, 19, 0.12)`.
3. **Ghost Insets**:
   - Verification pill indicators and inset code terminals feature a crisp `inset 0 0 0 1px #E5E4DE` for razor-sharp edge precision.

## Shapes

The shape system adopts **Level 1 (Soft)** geometry. Interfaces convey technical discipline; large pill shapes and playful circular elements are discarded in favor of architectural, precision-milled radiuses.

- **Base Components (Inputs, Buttons, Badges)**: `0.25rem` (4px). Provides enough softness to avoid clinical severity while preserving architectural tightness.
- **Containers & Metric Cards (`rounded-lg`)**: `0.5rem` (8px). Structural cards and dialogue sheets maintain subtle corner definitions.
- **Modal Sheets & Code Consoles (`rounded-xl`)**: `0.75rem` (12px). Maximum permissible border-radius across the entire design system.
- **Interactive Verification Dots & Indicators**: Exact 1:1 circular shapes (e.g., status pulse, verified glyph container).

## Components

### Buttons
- **Primary Action**: Solid `#1D5D3A` fill, white `#FFFFFF` text, `4px` border radius, `0 1px 2px rgba(0,0,0,0.08)` shadow. On hover, darken to `#194D31`. Active state: subtle scale down (`0.99`). Includes trailing directional arrow glyph (`→`) for progression flows.
- **Secondary Action**: Warm white `#FFFFFF` surface, `1px solid #CDCCC4` border, `#111413` text. On hover, background shifts to `#F4F3EF` with border `#1D5D3A`.
- **Tertiary / Ghost**: Transparent fill, `#194D31` text, hover background `rgba(29, 93, 58, 0.06)`.

### Chips & Verification Badges
- **Attestation Tag (Mono Tag)**: Uppercase `JetBrains Mono` at `10px`, letter-spacing `0.06em`. Background `#E8F5EE`, text `#194D31`, border `1px solid #C2E5D1`. Padding: `2px 8px`.
- **Telemetry Counter**: Background `#111413`, text `#B8FF66` (or `#FFFFFF`), `JetBrains Mono` `11px`, border radius `3px`.

### Verification Cards
- Background `#FFFFFF` with `1px solid #E5E4DE` border and soft ambient shadow (`0 2px 8px rgba(17,20,19,0.03)`).
- Card headers feature an integrated top-row status bar: left-aligned categorical label in `label-mono-tag`, right-aligned green verified pulse dot.

### Input Fields & Controls
- **Input Fields**: Height `40px`, background `#FFFFFF`, border `1px solid #E5E4DE`, corner radius `4px`, text `body-md`. Focus state uses `#1D5D3A` border with `0 0 0 3px rgba(29, 93, 58, 0.12)` halo ring.
- **Checkboxes & Radios**: `16px × 16px`, `3px` radius (checkbox) or circle (radio). Inactive state: `1.5px solid #CDCCC4`. Checked state: `#1D5D3A` fill with white indicator icon.

### Verified Code & Hash Displays
- Inline code blocks and cryptographic keys are framed inside `#F4F3EF` capsules with `1px solid #E5E4DE`, rendered exclusively in `JetBrains Mono` (`label-code`). Includes one-click copy button with instant state transition to verified green checkmark.
